# LAB SHEET – 5

## Riak and Neo4j

### AIM:

To understand key-value and graph-based NoSQL databases and perform database operations using Riak KV and Neo4j.

### PROGRAMS:

**Q1.** Install and configure Riak KV on Linux. Create a student bucket and perform key-value CRUD operations.

**Q2.** Create a user-session management system using Riak. Store session information in a user_sessions bucket and retrieve session details using keys.

**Q3.** Create user profiles and preferences using Riak KV. Store user information in JSON format and perform PUT and GET operations.

**Q4.** Create a shopping cart application using Riak. Add, update, retrieve and remove products from a shopping cart.

**Q5.** Demonstrate Riak data types such as strings, JSON objects and lists. Explain buckets, keys and values with examples.

**Q6.** Demonstrate read and write quorum in Riak. Explain how quorum settings affect data availability and consistency.

**Q7.** Demonstrate horizontal scaling in Riak. Explain how data is distributed across multiple nodes and how buckets store records.

**Q8.** Perform multiple transaction-like operations in Riak. Explain its limitations regarding atomicity and multi-record transactions.

**Q9.** Implement query-by-data functionality using Riak JSON user records. Retrieve users based on selected attributes using application-side filtering.

**Q10.** Demonstrate set operations in Riak. Store interests or categories and perform add, remove, membership and intersection operations.

**Q11.** Install and configure Neo4j. Create Student, Course and Department nodes with suitable relationships and visualize the graph.

**Q12.** Create a social network using Neo4j with Person nodes and FRIENDS_WITH, FOLLOWS and WORKS_AT relationships. Find friends and followers.

**Q13.** Create an e-commerce graph using Neo4j with Customer, Product, Category and Order nodes. Retrieve products purchased by customers.

**Q14.** Demonstrate transactions and consistency in Neo4j. Perform multiple CREATE, MATCH, SET and DELETE operations within a transaction.

**Q15.** Develop a simple Neo4j application using Python, Java or JavaScript. Perform CRUD operations using Cypher and explain graph database use cases, scalability and availability.

### RESULT:

Thus, Riak KV and Neo4j database models, key-value operations, graph relationships, transactions and scalability were studied.
